Privacy policy

Updated 24 October 2026.

Project-298 Backups is a private utility used by its owner. Google Drive access is requested only to create, verify, retrieve and replace this utility’s backup files in a dedicated folder. It does not request access to unrelated Drive files.

Backup content is encrypted before upload. Authorization tokens and encryption keys are stored in restricted configuration controlled by the owner. Google receives encrypted backup files and ordinary file metadata. The utility does not sell data, display advertising, or disclose Google user data to other parties.

After a new backup is successfully verified, the previous backup is permanently removed. Failed backups retain the previous verified copy. The owner can revoke access through Google Account security settings and delete the backup folder through Drive.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

This public page contains no backup content, credentials, or trading records. Contact is through the support email displayed on the Google authorization screen.
